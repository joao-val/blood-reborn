## ⚔️ 模组

### 💎 Hunter's Arsenal: Blood Pacts — v1.0

为变形武器加入全新的**特殊攻击**（变形形态下 R2+L2），灵感来自《艾尔登法环》的战技，并为《血源诅咒》重新打造。而这个模组的核心，是**血之契约**。

🩸 **每个契约都是一场交易：一份力量，一个代价。**

- 💎 你找到的**宝石**可能带有 **14 种契约**之一。宝石越强，契约越强（契约 1、2、3），代价也随之增长。
- 🏆 圣杯地牢越深，契约越多：世界中和浅层圣杯的宝石 60% 带有契约，中层 80%，最深层 90%。刷宝石重新变得值得。
- ✨ **卡丽尔符文**同样带有契约。
- 📜 每个契约在宝石和武器界面上都有独立的一行，支持游戏的全部 21 种语言。

你可能遇到的一些契约：

| 🩸 力量 | 💀 代价 |
|---|---|
| 生命低于 30% 时，耐力恢复更快 | 受到的伤害增加 |
| 采血瓶回复更多 | 最大耐力降低 |
| 内脏攻击返还一颗子弹和一次免费特殊攻击 | 受到的伤害增加 |
| 特殊攻击命中时吸回一些生命 | 生命会慢慢流失 |
| 特殊攻击命中时返还一颗水银子弹 | 最大子弹数减少 |
| 每次连续命中都提升攻击力 | 每次命中都提升你受到的伤害 |
| 完美闪避后短暂提升攻击力 | 闪避消耗更多耐力 |
| 洞察 40 以上时，特殊攻击更强 | 狂乱抗性降低 |
| 对野兽的伤害更高 | 对其他一切的伤害更低 |
| 回血（反击回复）也会恢复耐力 | 受到的伤害增加 |
| 更多水银子弹 | 特殊攻击多消耗一颗子弹 |

🔧 包含 9 个代码补丁（管理器会替你开启）。

### 🌙 Merciless Night — v1.31

夜晚变得更加残酷。🌑

首领、猎人与野兽都经过重做，带来**更有节奏、更现代、更具挑战性**的《血源诅咒》。我们不会剧透改了什么：你会在战斗中亲自发现。😈

💬 **非常欢迎反馈。**告诉我们哪里公平，哪里残酷，哪里*过于*残酷。

🔧 包含 1 个代码补丁（管理器会替你开启）。

### 🏮 Fogside Lantern — v1.6.1 *（测试中）*

在首领战中死了？你会在首领雾门外重生。不用再走很远的回头路。🚶‍♂️

### 🧪 Blood Vial Safety Net — v1.0.1 *（测试中）*

死亡并重生后，你的采血瓶会补回到 11 个。它只补足缺少的部分，绝不会在战斗中触发。💉

## 🧩 一起用更好

每个模组都可以单独使用，也可以一起使用。当两个模组修改同一个游戏文件时，会有一个小的兼容文件夹（**zCompat**）把两者合并。

## ✅ 你需要

- 🎮 已安装并能正常运行的 **BB Port**。
- 💿 你自己的《血源诅咒》游戏文件（CUSA03173），游戏版本 **1.09**。
- 💾 以防万一，把存档文件夹复制到安全的地方（BB Port 文件夹 ➜ `user` ➜ `savedata`）。

## 🧰 Blood Reborn 模组管理器 *（开发中）*

一个只为 Blood Reborn 模组制作的小型模组管理器。它**不会**启动游戏：你照常通过 BB Port 来玩。

- 📦 **安装、移除和更新**每个模组，显示已安装版本、最新版本和*更新内容*。
- 🔄 **在 GitHub 和 Nexus Mods 上检查更新**，无需登录。
  - 🐙 GitHub：一键下载。
  - ⭐ Nexus 高级会员：使用你的 API 密钥一键下载。
  - 🆓 Nexus 免费账号：它会打开文件页面，你点击*手动下载*，zip 一到你的“下载”文件夹，它就会自动安装。
- 🛠️ **解决与 `mods` 文件夹中任何其他模组的冲突**：能合并的会合并到加载顺序末尾的一个文件夹中，不能合并的会列出来，由你选择哪个模组优先（推荐选择 Blood Reborn）。
- 🛡️ 绝不写入你的游戏文件，也不改动其他人的模组。

✅ 更新功能：已完成。下一步：与任何模组的冲突处理（第 3 阶段）。

📐 设计文档（英文）：[docs/manager-design.md](docs/manager-design.md)

## 🔄 更新如何发布

[`catalog.json`](catalog.json) 列出每个模组的当前版本、每个版本的说明、下载（GitHub 发布版本中的附件）以及它在 Nexus Mods 上的页面。发布新版本就是：打包、附加到 GitHub 的发布版本、更新目录。管理器通过读取目录得知有什么新内容。
